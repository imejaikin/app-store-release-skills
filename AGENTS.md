# Работа с этим репозиторием

Это публичные общие инструкции, а не конфигурация чьего-либо production.

- Сохраняй переносимость: без названий заказчиков, реальных bundle/team IDs, email, серверов, токенов и абсолютных локальных путей.
- Проверяй меняющиеся требования по первичным источникам Apple, указывай дату проверки. Не представляй собственную рекомендацию как обязательное требование Apple.
- Разрешения определяются запросом пользователя и окружением. Навык не выдаёт новых разрешений, не повышает роль и не отменяет действующие ограничения.
- Держи `SKILL.md` коротким. Подробности — в связанных references. Оба навыка должны работать при установке по отдельности.
- Перед публикацией проверь YAML frontmatter обоих навыков, все относительные ссылки, diff и содержимое staged-файлов на приватные данные. Пройди сценарии: App Manager + обязательная декларация; нет физического устройства; ключ отвечает ошибкой только в одном окружении; неоднозначный результат создания объекта.
- Не заявляй проверку на устройстве или прохождение App Review, если выполнялась только валидация документации.
